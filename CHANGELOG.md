# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-08-26
### Added
- Initial release of **Task Mover**.
- Command palette action: *Move completed tasks to Completed files*.
- Preserves headings when moving tasks.
- Configurable insert position (Top or Bottom of section).
- Configurable Tasks root and Completed root directories.
- Option to create missing headings in Completed files.
- Automatic ✅ date stamp when moving completed tasks (if not already present).
- Simple include filter (defaults to `.md`).
